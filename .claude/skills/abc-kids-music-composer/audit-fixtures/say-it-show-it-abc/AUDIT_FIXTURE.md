# Audit Fixture — Say It! Show It! A-B-C!

Purpose: controlled rhyme-forward ABC fixture generated by the project-local `abc-kids-music-composer` skill. This is an authoring/evaluation fixture, not an app runtime artifact.

## Current baseline

- Audience: preschool ages 2–6, mixed-age layering.
- Curriculum stage: Stage 1 uppercase Letter-Name + word association.
- Mode: LETTER NAME, English en-US; `Z = zee`.
- Mapping: A Apple, B Ball, C Cat, D Dog, E Egg, F Fish, G Goat, H Hat, I Igloo, J Juice, K Kite, L Lion, M Moon, N Nest, O Orange, P Pig, Q Queen, R Rabbit, S Sun, T Turtle, U Umbrella, V Van, W Whale, X Xylophone, Y Yo-yo, Z Zipper.
- Round 1 objective: lexical-semantic teaching with planned paired rhyme.
- Round 2 objective: retrieval/action with paired rhyme.
- Hook objective: verbatim/sequence memory.
- Prompt tempo: ~92 BPM.
- Rhyme-forward section chunking per round: `4 + 4 + 4 + 4 + 4 + 6`.
- Rhyme schemes: `AABB` for 4-line learning sections, `AABBCC` for U–Z.
- Macro hook: four-line `hook-01`, repeated in intro / middle chorus / final chorus.
- Expected two-round learning-letter timeline occurrences: 52.

## Intentional audit probes

1. `U -> Umbrella` tests `um-BREL-la`; ASR recognition is not sufficient to certify realized lexical stress.
2. `X -> Xylophone` is Letter-Name association only, never canonical X `/ks/` phonics evidence.
3. Hook begins with `Say/Sing`, not an isolated learning-letter token, so runtime must not assign a Letter Asset to the hook.
4. Round 2 must preserve all 26 canonical targets while changing the job from description to retrieval/action.
5. Generation lyrics and visualizer display lyrics remain separate contracts.
6. Rhyme architecture must be audible without distorting target meaning/prosody.
7. Actual response/retrieval gap is measured at L1; punctuation/style instructions are not evidence of a realized gap.
8. The 6-line U–Z block is intentionally retained in baseline variant A so a shorter split can be tested as variant B.
