[Intro]
Build the joint, connect the motor, wire the sensor, load firmware, test slowly, compare feedback.
Debugging is part of building, not proof the project failed.

[Verse 1]
A — Arduino Board! | Microcontroller development-board family; processor, voltage, and pins depend on model.
B ... B ... Battery! | Electrochemical device converts stored chemical energy to electrical energy; polarity, voltage, chemistry, charging, and disposal must match the device.
C? Capacitor! | Component stores electric charge/energy in an electric field; capacitance, voltage rating, polarity for some types, and discharge matter.
D is Daughter Board. Secondary circuit board plugs/connects to a main board to add specialized functions. |

[Verse 2]
E — Encoder Wheel! | Patterned wheel/disc works with a sensor to encode rotation; slot/mark count affects resolution.
F ... F ... Firmware! | Software stored close to hardware controls low-level device behavior; it can be updated but must match device/version.
G? Gearbox! | Mechanical gear train changes speed, torque, or direction between input and output shafts.
H is Heat Sensor. Broad sensor label for temperature/thermal detection; thermistors, IC sensors, thermocouples, and infrared sensors measure differently. |

[Chorus]
Build, test, check—A-B-C!
Feedback tells the next revision.

[Verse 3]
I — Interface Board! | Board adapts connectors, voltage levels, signals, or protocols between subsystems.
J ... J ... Joystick! | Human input control reports direction and sometimes buttons/axes; it sends commands rather than directly moving a robot joint.
K? Keyboard! | Key-based input device sends codes/commands to a computer or controller; software interprets those inputs.
L is Logic Gate. Digital circuit implements Boolean operations such as AND, OR, or NOT on logic-level inputs. |

[Verse 4]
M — Motor! | Electromechanical actuator converts electrical energy into rotational or linear mechanical motion depending type.
N ... N ... Network Cable! | Wired medium carries data signals between network devices; connector/category and supported speed depend on cable standard.
O? Optical Sensor! | Sensor responds to light using photodiodes, phototransistors, imaging elements, or other optical methods.
P is Power Supply. Source converts/provides electrical power at specified voltage/current; current capability and polarity must match load. |

[Chorus]
Build, test, check—A-B-C!
Feedback tells the next revision.

[Verse 5]
Q — Quantum Sensor! | Sensor class uses quantum effects for precise measurement; it is not a quantum computer by definition.
R ... R ... Robot Arm! | Mechanical linkage with joints/actuators positions an end effector; controller and program determine commanded motion.
S? Servo! | Actuator system uses feedback to control position, speed, or torque; hobby servos typically combine motor, gears, sensor, and controller.
T is Touch Sensor. Sensor detects contact or touch-related changes using capacitive, resistive, force, or other methods. |

[Verse 6]
U — USB Cable! | Cable carries power and/or data under USB standards; connector shape alone does not guarantee supported power or data rate.
V ... V ... Voltage Regulator! | Circuit maintains or converts output voltage within a specified range; it cannot safely ignore current, heat, or input limits.
W? Wheel Encoder! | Encoder measures wheel rotation to estimate speed/distance; wheel slip means estimated travel can differ from true ground movement.
X is X-shaped Robot Arm. Project robot-arm model with X-like geometry; shape is a visual clue and does not define a standard industrial kinematic type. |

[Chorus]
Build, test, check—A-B-C!

[Verse 7]
Y — Yaw Sensor! | Project label for sensor estimating rotation about a vertical/yaw axis, often using gyroscope or fused inertial data; drift/calibration can matter.
Z ... Z ... Z-axis Sensor! | Project sensor assigned to a Z-axis measurement in a coordinate system; axis meaning depends on machine orientation and sensor type.
